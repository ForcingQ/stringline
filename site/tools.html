Tools

One card per released tool: what it is, the first thing to do, the one gotcha, and what it has caught.

What it has caught is read from the tool's own run log, and counts real runs only, never a planted fault. A tool still being built has no card here; the build room names it as in progress.

The earlier work this recreates is not shown. That it mirrors that work is the owner's claim, dated. What you can check: whether each tool fires on its planted fault, and what its run log shows.
