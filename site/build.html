The build

The record of how this is built, session by session:

  • BUILD-LOG.md: what each session did, decided and got wrong, dated.
  • DECISIONS.md: each decision and its reason.
  • MAP.md: what depends on what, and the order it sets.
  • SPEC.md: what is built next, precisely enough to build it.

The work runs in lanes, each with the finished list it wrote before it started. Tools still being built are named below, in progress.

The earlier work this recreates is not shown. That it mirrors that work is the owner's claim, dated. What you can check: whether each tool fires on its planted fault, and what its run log shows.
